Theme

A · Flat vector

  • Crisp at any size and on any screen density.
  • All motion is CSS transforms, so it costs almost no CPU.
  • Easiest style to extend with new scenes and props.

B · Pixel art

  • Retro charm that suits the cheeky tone.
  • Drawn on a 160×88 canvas at about 15 fps, so it's cheap but runs a small JS loop.
  • Sharpest at whole-number scales. Text uses a pixel font.
